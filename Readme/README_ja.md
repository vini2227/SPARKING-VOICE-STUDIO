# Sparking Zero Voice Studio — ポータブル版

## インストール
1. ZIP 全体を「ドキュメント」など書き込み可能なフォルダーに展開します。ZIP 内から実行したり、Program Files に配置したりしないでください。
2. `Sparking Zero Voice Studio.exe` を開きます。Python、音声ツール、UnrealPak、Oodle は同梱済みです。Python、Codex、Excel の別途インストールは不要です。`Preparar ferramentas.bat` は任意のツール確認用です。
3. 設定でゲームのインストールフォルダーを選びます。Replacer では CustomProject と Custom Engine を空欄にするとゲームから参照データを読み取ります。パッケージキーは自動設定され、`keys.json` は不要です。
4. 設定を保存して音声バンクを開きます。新規インストールの初期言語は英語です。フォルダー選択前でも言語を変更できます。更新時に既存の `settings.json` を引き継ぐと選択済みの言語を保持します。

## 必要環境
- 64 ビット版 Windows 10 または 11、.NET Framework 4.8、同梱 Unreal ツールに対応する 64 ビット Visual C++ ランタイム。
- 使用するバージョンの `.pak`、`.utoc`、`.ucas` を含む、インストール済み DRAGON BALL Sparking! ZERO。
- **Custom Engine と CustomProject は同梱されていません。** Custom 出力には、CriWare プラグインとその DLL を備えた対応 Unreal 5.1 Custom Engine、および互換性のある音声参照を含む CustomProject が必要です。通常の Unreal だけでは不十分です。
- Replacer では CustomProject は任意です。指定するとそこから参照を読み、未指定ならゲームから読みます。ゲームコンテナーが変わるとキャッシュを更新します。

## 主な機能
- US/JP バンク、各言語の公式キャラクター名、Cue IDs、機能、インタラクションタグ、フィルター、重複音声、元音声と編集音声の比較。
- 音声・動画・外部音声パッケージの取り込み、マイク録音、トリミング、ゲイン調整、クリッピング補正、音量最大化。
- ローカルでの音声改善、背景分離、リバーブ・エコー・ピッチ・低音/高音・二重音声・歪み・ラジオ効果。適用前に試聴してください。品質は録音に依存します。
- 速度 0.25x～3.00x、ピッチ維持は初期状態で有効（無効化可能）、試聴、取り消し/やり直し。ピッチを維持するとテンポのみ変更します。
- 保存と復旧、最近のプロジェクト、共有/統合、バンク移行、タグ/機能による音声コピー。Ctrl+Z で取り消し、Ctrl+Y または Ctrl+Shift+Z でやり直し。画面とヘルプは 16 言語対応。
- ゲームと同一と確認された外部音声は置換音声ではなく元音声として扱います。外部音声の試聴は相違が確認されたものに限定されます。未置換音声は元音声を残すか無音にするか選べます。

## Replacer と Custom の出力
**Replacer:** `.pak`、`.utoc`、`.ucas` を同じ Mod フォルダーに出力します。置換対象は元のバンクで決まり、プロジェクト名やフォルダー名を変えても対象は変わりません。フォルダー名が空欄なら、アプリ言語のベースキャラクター公式名を使用します。カスタムキャラクターの Mod はインストールしたままにしてください。音声パッケージにキャラクター自体は含まれません。取り込み時は関連 PAK/UTOC/UCAS を一緒に保管します。Replacer は Unreal Editor を起動しません。

**Custom:** `.uasset` は Unreal 用 Mod フォルダー、`.pak` はゲーム用 Mod フォルダーへ、それぞれ「Custom」接頭辞付きで出力します。中間ファイルとレポートは補助フォルダーです。フォルダー名はアプリ言語に従います。プロジェクト名は Unreal の `Plugins` 内にある Mod/プラグインフォルダー名と完全一致させます。バンク名はカスタムキャラクター ID と US/JP に対応させます。設定で CustomProject と Custom Engine を選択します。

出力はプロジェクト番号と名前で整理されます。各版は増加する番号で始まり、名前順なら最新が最後になります。フォルダーを開くメニューは出力、編集音声、プロジェクトの順です。プロジェクト未選択時は共通出力フォルダーを開きます。必ずゲーム内で確認してください。

## プロジェクトとバックアップ
更新前にアプリを終了し、既存フォルダーをバックアップします。新しいZIPを同じインストール先に展開し、フォルダーを統合してプログラムのファイルを上書きします。Projects、Cache、settings.json、設定、カウンター、プリセットは保持してください。これらの個人ファイルは新しいZIPに含まれません。アプリのフォルダーを二重に作らないでください。古いプロジェクトには音声の絶対パスが含まれる場合があるため、場所を変えないでください。新しい任意項目がない旧プロジェクトもサポートします。UPDATE.mdを参照してください。

## トラブルと同梱内容
アクセス拒否時は「ドキュメント」など書き込み可能なフォルダーに展開します。フォルダーを開く際は Windows Explorer でも再試行しますが、管理者権限は求めず Windows のアクセス権も変更しません。Custom 読み込みエラーは表示された `import.log` と対応 Engine/CriWare を確認します。アセットは対象バンクとゲーム版に合う必要があります。

個人プロジェクト、録音、出力、キャッシュ、ゲーム/参照アセット、作者の個人設定は同梱されません。標準キーとツールは同梱されます。ライセンスはランタイムとライブラリーに付属し、音声エンジンのクレジットは `Tools/VoiceAI/NOTICE.txt` にあります。サポートにはアプリ/ゲーム版、バンク、出力モード、ログを添えてください。ローカル検証はゲーム内テストの代わりにはなりません。
