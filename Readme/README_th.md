# Sparking Zero Voice Studio — รุ่นพกพา

## การติดตั้ง
1. แตกไฟล์ ZIP ทั้งหมดลงในโฟลเดอร์ที่เขียนได้ เช่น Documents อย่ารันจากภายใน ZIP หรือติดตั้งใน Program Files
2. เปิด `Sparking Zero Voice Studio.exe` มี Python เครื่องมือเสียง UnrealPak และ Oodle มาให้แล้ว ไม่ต้องติดตั้ง Python, Codex หรือ Excel เพิ่ม `Preparar ferramentas.bat` เป็นตัวตรวจสอบเครื่องมือที่เลือกใช้ได้
3. เลือกโฟลเดอร์ติดตั้งเกมในการตั้งค่า สำหรับ Replacer ให้เว้น CustomProject และ Custom Engine ว่างเพื่ออ่านข้อมูลอ้างอิงจากเกม คีย์แพ็กเกจตั้งค่าอัตโนมัติ ไม่ต้องใช้ `keys.json`
4. บันทึกแล้วเปิดธนาคารเสียง การติดตั้งใหม่เริ่มเป็นภาษาอังกฤษ เปลี่ยนภาษาได้ก่อนเลือกโฟลเดอร์ หากอัปเดตโดยเก็บ `settings.json` เดิมไว้ ภาษาที่เลือกจะยังอยู่

## ความต้องการระบบ
- Windows 10 หรือ 11 แบบ 64 บิต, .NET Framework 4.8 และ Visual C++ runtime แบบ 64 บิตที่เข้ากับเครื่องมือ Unreal ที่ให้มา
- DRAGON BALL Sparking! ZERO ที่ติดตั้งแล้ว พร้อมไฟล์ `.pak`, `.utoc` และ `.ucas` ของเกมเวอร์ชันที่ใช้
- **ไม่รวม Custom Engine และ CustomProject** การส่งออก Custom ต้องใช้ Unreal 5.1 Custom Engine ที่เข้ากันได้ พร้อมปลั๊กอิน CriWare และ DLL รวมถึง CustomProject ที่มีข้อมูลอ้างอิงเสียงที่เข้ากันได้ Unreal ทั่วไปเพียงอย่างเดียวไม่เพียงพอ
- CustomProject เป็นตัวเลือกสำหรับ Replacer หากตั้งค่าไว้จะใช้ข้อมูลอ้างอิงจากที่นั่น มิฉะนั้นจะอ่านจากเกมและอัปเดตแคชเมื่อคอนเทนเนอร์เกมเปลี่ยน

## ฟังก์ชันหลัก
- ธนาคาร US/JP ชื่อตัวละครทางการตามภาษา Cue IDs หน้าที่ แท็กปฏิสัมพันธ์ ตัวกรอง เสียงซ้ำ และการเปรียบเทียบเสียงต้นฉบับกับเสียงที่แก้ไข
- นำเข้าเสียง วิดีโอ และแพ็กเกจเสียงภายนอก; บันทึกไมโครโฟน; ตัดเสียง ปรับเกน แก้ clipping และเพิ่มความดังสูงสุด
- ปรับปรุงเสียง แยกพื้นหลัง และเอฟเฟกต์ภายในเครื่อง: reverb, echo, pitch, ทุ้ม/แหลม เสียงคู่ distortion และวิทยุ ฟังตัวอย่างก่อนใช้ คุณภาพขึ้นกับการบันทึก
- ความเร็ว 0.25x–3.00x โดยคงระดับเสียงเป็นค่าเริ่มต้น (ปิดได้) ตัวอย่าง และเลิกทำ/ทำซ้ำ คงระดับเสียงเพื่อเปลี่ยนเฉพาะจังหวะ
- บันทึกและกู้คืน โปรเจกต์ล่าสุด แชร์/รวม ย้ายธนาคาร และคัดลอกตามแท็ก/หน้าที่ Ctrl+Z เลิกทำ; Ctrl+Y หรือ Ctrl+Shift+Z ทำซ้ำ อินเทอร์เฟซและคู่มือรองรับ 16 ภาษา
- เสียงภายนอกที่ยืนยันว่าเหมือนเกมถือเป็นต้นฉบับ ไม่ใช่เสียงแทน ฟังตัวอย่างภายนอกได้เฉพาะเสียงที่ยืนยันว่าต่าง เลือกคงเสียงเดิมหรือทำให้เงียบสำหรับเสียงที่ยังไม่แทนที่

## การส่งออก Replacer และ Custom
**Replacer:** ส่ง `.pak`, `.utoc` และ `.ucas` ไว้ด้วยกันในโฟลเดอร์ม็อด ธนาคารเดิมกำหนดตัวละครที่ถูกแทน การเปลี่ยนชื่อโปรเจกต์หรือโฟลเดอร์ไม่เปลี่ยนเป้าหมาย หากชื่อโฟลเดอร์ว่างจะใช้ชื่อทางการของตัวละครฐานตามภาษาแอป ต้องเก็บม็อดตัวละครกำหนดเองไว้ เพราะแพ็กเกจเสียงไม่รวมตัวละคร เมื่อนำเข้าให้เก็บ PAK/UTOC/UCAS ที่เกี่ยวข้องไว้ด้วยกัน Replacer ไม่เปิด Unreal Editor

**Custom:** ส่ง `.uasset` ไปยังโฟลเดอร์ม็อดสำหรับ Unreal และ `.pak` ไปยังโฟลเดอร์ม็อดสำหรับเกม โดยมีคำนำหน้า “Custom”; ไฟล์ระหว่างทางและรายงานอยู่ในโฟลเดอร์ช่วยเหลือ ชื่อโฟลเดอร์ตามภาษาแอป ชื่อโปรเจกต์ต้องตรงกับชื่อโฟลเดอร์ม็อด/ปลั๊กอินใน `Plugins` ของ Unreal ทุกตัวอักษร ธนาคารต้องตรงกับ ID ตัวละครกำหนดเองและ US/JP เลือก CustomProject และ Custom Engine ในการตั้งค่า

ไฟล์ส่งออกจัดตามหมายเลขและชื่อโปรเจกต์ แต่ละเวอร์ชันเริ่มด้วยเลขที่เพิ่มขึ้น ทำให้ล่าสุดอยู่ท้ายเมื่อเรียงตามชื่อ เมนูเปิดโฟลเดอร์แสดงไฟล์ส่งออก เสียงที่แก้ไข และโปรเจกต์ตามลำดับ ถ้าไม่มีโปรเจกต์จะเปิดโฟลเดอร์ส่งออกรวม ทดสอบในเกมเสมอ

## โปรเจกต์และสำรองข้อมูล
ปิดแอปและสำรองโฟลเดอร์เดิมก่อนอัปเดต แตก ZIP ใหม่ในตำแหน่งติดตั้งเดิม รวมโฟลเดอร์และแทนที่ไฟล์โปรแกรม เก็บ Projects, Cache, settings.json การตั้งค่า ตัวนับ และพรีเซ็ตไว้ ไฟล์ส่วนตัวไม่รวมใน ZIP ใหม่ อย่าสร้างโฟลเดอร์แอปซ้อนอีกชั้น คงตำแหน่งเดิมเพราะโปรเจกต์เก่าอาจมีพาธเสียงแบบเต็ม รองรับโปรเจกต์เก่าที่ไม่มีฟิลด์เสริมใหม่ ดู UPDATE.md

## ปัญหาและไฟล์ที่รวมมา
หากถูกปฏิเสธการเข้าถึง ให้แตกไฟล์ในโฟลเดอร์ที่เขียนได้ เช่น Documents การเปิดโฟลเดอร์ลองใหม่ด้วย Windows Explorer โดยไม่ขอสิทธิ์ผู้ดูแลหรือเปลี่ยนสิทธิ์ Windows สำหรับข้อผิดพลาด Custom ให้ตรวจ `import.log` ที่แอประบุและ Engine/CriWare ที่เข้ากันได้ assets ต้องตรงกับธนาคารและเวอร์ชันที่ต้องการ

แพ็กเกจไม่รวมโปรเจกต์ส่วนตัว เสียงบันทึก ไฟล์ส่งออก แคช assets เกม/อ้างอิง หรือการตั้งค่าส่วนตัวผู้สร้าง มีคีย์มาตรฐานและเครื่องมือมาให้ ใบอนุญาตอยู่กับ runtime และไลบรารี เครดิตเอนจินเสียงใน `Tools/VoiceAI/NOTICE.txt` เมื่อติดต่อช่วยเหลือให้แจ้งเวอร์ชันแอป/เกม ธนาคาร โหมด และ log การตรวจในเครื่องไม่แทนการทดสอบในเกม
