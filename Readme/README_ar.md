# Sparking Zero Voice Studio — النسخة المحمولة

## التثبيت
1. فك ضغط ملف ZIP بالكامل في مجلد يمكنك الكتابة فيه، مثل المستندات. لا تشغّل التطبيق داخل ZIP ولا تثبّته في Program Files.
2. افتح `Sparking Zero Voice Studio.exe`. يتضمن Python وأدوات الصوت وUnrealPak وOodle؛ لا تحتاج إلى تثبيت Python أو Codex أو Excel بشكل منفصل. الملف `Preparar ferramentas.bat` لفحص الأدوات اختياريًا.
3. اختر مجلد تثبيت اللعبة من الإعدادات. في Replacer، اترك CustomProject وCustom Engine فارغين لقراءة المراجع من اللعبة. يُضبط مفتاح الحزم تلقائيًا، ولا تحتاج إلى `keys.json`.
4. احفظ الإعدادات وافتح بنك أصوات. تبدأ التثبيتات الجديدة بالإنجليزية. يمكنك تغيير اللغة قبل اختيار المجلدات. الاحتفاظ بملف `settings.json` الحالي عند التحديث يحافظ على اللغة المختارة.

## المتطلبات
- Windows 10 أو 11 بنظام 64 بت، و.NET Framework 4.8 ومكتبات Visual C++ ذات 64 بت المتوافقة مع أدوات Unreal المرفقة.
- نسخة مثبتة من DRAGON BALL Sparking! ZERO تشمل ملفات `.pak` و`.utoc` و`.ucas` لإصدار اللعبة المستخدم.
- **Custom Engine وCustomProject غير مرفقين.** يتطلب تصدير Custom محرك Custom Engine متوافقًا من Unreal 5.1 مع إضافة CriWare وملفات DLL الخاصة بها، وCustomProject بمراجع صوتية متوافقة. تثبيت Unreal عادي لا يكفي.
- CustomProject اختياري في Replacer. عند ضبطه يوفر المراجع؛ وإلا يقرأها التطبيق من اللعبة ويحدّث التخزين المؤقت عند تغير حاوياتها.

## الميزات الرئيسية
- بنوك US/JP وأسماء الشخصيات الرسمية المترجمة وCue IDs والوظائف ووسوم التفاعلات والمرشحات والأصوات المتكررة، ومقارنة الصوت الأصلي والمعدّل.
- استيراد الصوت والفيديو وحزم الأصوات الخارجية؛ التسجيل بالميكروفون؛ القص والتحكم في الكسب وتصحيح التشبع وتعظيم مستوى الصوت.
- تحسين الصوت وعزل الخلفية والمؤثرات محليًا: الصدى والتردد وطبقة الصوت والجهير/الحدّة والصوت المزدوج والتشويه والراديو. استمع إلى المعاينة قبل التطبيق؛ تعتمد الجودة على التسجيل.
- سرعة من 0.25x إلى 3.00x مع الحفاظ على طبقة الصوت افتراضيًا (يمكن تعطيله) والمعاينة والتراجع/الإعادة. الحفاظ على الطبقة يغيّر الإيقاع فقط.
- الحفظ والاسترداد والمشاريع الأخيرة والمشاركة/الدمج وترحيل البنوك والنسخ حسب الوسوم/الوظائف. Ctrl+Z للتراجع، وCtrl+Y أو Ctrl+Shift+Z للإعادة. الواجهة والمساعدة بـ16 لغة.
- تُعامل الأصوات الخارجية المؤكد تطابقها مع اللعبة كأصوات أصلية لا كبدائل. معاينتها متاحة فقط للاختلافات المؤكدة. اختر إبقاء الصوت الأصلي أو الصمت للأصوات غير المستبدلة.

## تصدير Replacer وCustom
**Replacer:** يضع `.pak` و`.utoc` و`.ucas` معًا في مجلد المود. يحدد البنك الأصلي الشخصية المستبدلة؛ تغيير اسم المشروع أو المجلد لا يغيّر الهدف. يستخدم اسم المجلد الفارغ الاسم الرسمي للشخصية الأساسية بلغة التطبيق. أبقِ مود الشخصية المخصصة مثبتًا؛ حزمة الصوت لا تتضمن الشخصية. عند الاستيراد، أبقِ ملفات PAK/UTOC/UCAS المرتبطة معًا. لا يشغّل Replacer محرر Unreal.

**Custom:** يضع `.uasset` في مجلد المود لـUnreal و`.pak` في مجلد المود للعبة، ببادئة «Custom»؛ وتوضع الملفات الوسيطة والتقارير في مجلد مساعد. تتبع الأسماء لغة التطبيق. يجب أن يطابق اسم المشروع تمامًا مجلد المود/الإضافة ضمن `Plugins` في Unreal. يجب أن يطابق البنك معرّف الشخصية المخصصة وUS/JP. اختر CustomProject وCustom Engine من الإعدادات.

تُجمع الصادرات حسب رقم المشروع واسمه. تبدأ كل نسخة برقم متزايد لتظهر الأحدث أخيرًا عند الفرز بالاسم. قائمة فتح المجلد تعرض الصادرات ثم الصوت المعدّل ثم المشاريع؛ دون مشروع تفتح مجلد الصادرات العام. اختبر النتيجة داخل اللعبة دائمًا.

## المشاريع والنسخ الاحتياطية
أغلق التطبيق واحتفظ بنسخة احتياطية من المجلد قبل التحديث. فك ZIP الجديد في موقع التثبيت نفسه وادمج المجلدات واستبدل ملفات البرنامج. احتفظ بـ Projects وCache وsettings.json والتفضيلات والعدادات والإعدادات المسبقة؛ لا يتضمن ZIP الملفات الشخصية. لا تنشئ مجلداً إضافياً متداخلاً للتطبيق. أبق الموقع نفسه لأن المشاريع القديمة قد تحتوي مسارات صوت مطلقة. المشاريع القديمة التي تفتقر إلى الحقول الاختيارية الجديدة مدعومة. راجع UPDATE.md.

## المشكلات والملفات المرفقة
عند رفض الوصول، استخرج في مجلد قابل للكتابة مثل المستندات. يحاول فتح المجلد مجددًا بمستكشف Windows، دون طلب صلاحيات المسؤول أو تغيير الأذونات. لأخطاء Custom راجع مسار `import.log` المعروض وتوافق Engine/CriWare. يجب أن تطابق الأصول البنك والإصدار المقصودين.

لا تتضمن الحزمة مشاريع أو تسجيلات أو صادرات أو ذاكرة مؤقتة شخصية، ولا أصول اللعبة/المراجع أو إعدادات المؤلف. المفتاح القياسي والأدوات مرفقة. ترافق التراخيص بيئة التشغيل والمكتبات؛ اعتمادات محركات الصوت في `Tools/VoiceAI/NOTICE.txt`. للدعم أرسل إصدار التطبيق/اللعبة والبنك ووضع التصدير والسجل. الفحص المحلي لا يحل محل الاختبار داخل اللعبة.
