# Sparking Zero Voice Studio — 포터블 버전

## 설치
1. ZIP 전체를 문서 등 쓰기 가능한 폴더에 압축 해제하세요. ZIP 안에서 실행하거나 Program Files에 설치하지 마세요.
2. `Sparking Zero Voice Studio.exe`를 여세요. Python, 오디오 도구, UnrealPak, Oodle이 포함되어 있으므로 Python, Codex, Excel을 따로 설치할 필요가 없습니다. `Preparar ferramentas.bat`는 선택적인 도구 확인입니다.
3. 설정에서 게임 설치 폴더를 선택하세요. Replacer는 CustomProject와 Custom Engine을 비워 두면 게임에서 참조를 읽습니다. 패키지 키는 자동 설정되므로 `keys.json`이 필요 없습니다.
4. 설정을 저장하고 음성 뱅크를 여세요. 새 설치의 기본 언어는 영어입니다. 폴더를 선택하기 전에도 언어를 바꿀 수 있습니다. 업데이트 시 기존 `settings.json`을 유지하면 선택한 언어가 보존됩니다.

## 요구 사항
- 64비트 Windows 10 또는 11, .NET Framework 4.8 및 포함된 Unreal 도구와 호환되는 64비트 Visual C++ 런타임.
- 사용하는 게임 버전의 `.pak`, `.utoc`, `.ucas` 파일이 있는 설치된 DRAGON BALL Sparking! ZERO.
- **Custom Engine과 CustomProject는 포함되지 않습니다.** Custom 내보내기에는 CriWare 플러그인과 DLL이 있는 호환 Unreal 5.1 Custom Engine 및 호환 음성 참조를 가진 CustomProject가 필요합니다. 일반 Unreal 설치만으로는 충분하지 않습니다.
- Replacer에서 CustomProject는 선택 사항입니다. 설정하면 해당 참조를 사용하고, 아니면 게임에서 읽습니다. 게임 컨테이너가 바뀌면 캐시가 갱신됩니다.

## 주요 기능
- US/JP 뱅크, 공식 현지화 캐릭터 이름, Cue IDs, 기능, 상호작용 태그, 필터, 반복 음성 및 원본/편집 음성 비교.
- 오디오, 비디오, 외부 음성 패키지 가져오기; 마이크 녹음; 자르기, 게인 조절, 클리핑 보정, 볼륨 최대화.
- 로컬 음성 개선, 배경 분리 및 리버브, 에코, 피치, 저음/고음, 이중 음성, 왜곡, 라디오 효과. 적용 전 미리 들어 보세요. 품질은 녹음에 따라 달라집니다.
- 0.25x~3.00x 속도, 음높이 유지 기본 활성화(해제 가능), 미리 듣기, 실행 취소/다시 실행. 음높이를 유지하면 템포만 바뀝니다.
- 저장과 복구, 최근 프로젝트, 공유/병합, 뱅크 마이그레이션, 태그/기능별 복사. Ctrl+Z는 실행 취소, Ctrl+Y 또는 Ctrl+Shift+Z는 다시 실행입니다. 인터페이스와 도움말은 16개 언어를 지원합니다.
- 게임과 동일하다고 확인된 외부 음성은 대체 음성이 아닌 원본으로 처리됩니다. 외부 미리 듣기는 차이가 확인된 음성만 가능합니다. 교체되지 않은 음성은 원본 유지 또는 무음으로 선택할 수 있습니다.

## Replacer와 Custom 내보내기
**Replacer:** `.pak`, `.utoc`, `.ucas`를 모드 폴더에 함께 내보냅니다. 원본 뱅크가 교체 대상 캐릭터를 결정하며 프로젝트나 폴더 이름 변경은 대상을 바꾸지 않습니다. 폴더 이름이 비어 있으면 앱 언어의 기본 캐릭터 공식 이름을 사용합니다. 커스텀 캐릭터 자체의 모드는 계속 설치되어 있어야 합니다. 음성 패키지에는 캐릭터가 포함되지 않습니다. 가져올 때 관련 PAK/UTOC/UCAS를 함께 보관하세요. Replacer는 Unreal Editor를 실행하지 않습니다.

**Custom:** `.uasset`는 Unreal용 모드 폴더에, `.pak`는 게임용 모드 폴더에 각각 “Custom” 접두사로 저장합니다. 중간 파일과 보고서는 보조 폴더로 갑니다. 폴더 이름은 앱 언어를 따릅니다. 프로젝트 이름은 Unreal의 `Plugins` 아래 모드/플러그인 폴더 이름과 정확히 같아야 합니다. 뱅크는 커스텀 캐릭터 ID와 US/JP에 맞아야 합니다. 설정에서 CustomProject와 Custom Engine을 선택하세요.

내보내기는 프로젝트 번호와 이름으로 그룹화됩니다. 각 버전은 증가하는 번호로 시작하여 이름순 정렬 시 최신 버전이 마지막에 위치합니다. 폴더 열기는 내보내기, 편집 오디오, 프로젝트 순입니다. 열린 프로젝트가 없으면 전체 내보내기 폴더를 엽니다. 항상 게임 안에서 테스트하세요.

## 프로젝트와 백업
업데이트 전에 앱을 종료하고 기존 폴더를 백업하세요. 새 ZIP을 같은 설치 위치에 풀고 폴더를 병합하여 프로그램 파일을 덮어쓰세요. Projects, Cache, settings.json, 환경설정, 카운터와 프리셋은 유지하세요. 개인 파일은 새 ZIP에 포함되지 않습니다. 앱 폴더를 이중으로 만들지 마세요. 이전 프로젝트에 오디오 절대 경로가 있을 수 있으므로 위치를 유지하세요. 새 선택 필드가 없는 이전 프로젝트도 지원합니다. UPDATE.md를 참고하세요.

## 문제 해결과 포함 파일
접근 거부가 발생하면 문서 같은 쓰기 가능한 폴더에 압축을 해제하세요. 폴더 열기는 Windows 탐색기로도 재시도하며 관리자 권한을 요청하거나 Windows 권한을 변경하지 않습니다. Custom 오류는 표시된 `import.log`와 호환 Engine/CriWare를 확인하세요. 에셋은 대상 뱅크와 버전에 맞아야 합니다.

개인 프로젝트, 녹음, 내보내기, 캐시, 게임/참조 에셋, 제작자 개인 설정은 포함되지 않습니다. 기본 키와 도구는 포함됩니다. 라이선스는 런타임 및 라이브러리와 함께 있으며 음성 엔진 크레딧은 `Tools/VoiceAI/NOTICE.txt`에 있습니다. 지원 요청에는 앱/게임 버전, 뱅크, 모드, 로그를 제공하세요. 로컬 검증은 게임 내 테스트를 대신하지 않습니다.
