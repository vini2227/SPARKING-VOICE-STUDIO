# Sparking Zero Voice Studio — Портативная версия

## Установка
1. Распакуйте весь ZIP в папку с правом записи, например «Документы». Не запускайте приложение внутри ZIP и не устанавливайте его в Program Files.
2. Откройте `Sparking Zero Voice Studio.exe`. Python, аудиоинструменты, UnrealPak и Oodle включены; отдельно устанавливать Python, Codex или Excel не нужно. `Preparar ferramentas.bat` выполняет необязательную проверку инструментов.
3. В настройках выберите папку установленной игры. Для Replacer оставьте CustomProject и Custom Engine пустыми, чтобы читать эталонные данные из игры. Ключ пакетов настроен автоматически; `keys.json` не нужен.
4. Сохраните настройки и откройте голосовой банк. Новые установки запускаются на английском. Язык можно изменить до выбора папок. При обновлении с сохранением вашего `settings.json` выбранный язык сохраняется.

## Требования
- Windows 10 или 11, 64 бита; .NET Framework 4.8 и среда Visual C++ для 64 бит, совместимая с включёнными инструментами Unreal.
- Установленная DRAGON BALL Sparking! ZERO с файлами `.pak`, `.utoc` и `.ucas` вашей версии игры.
- **Custom Engine и CustomProject не включены.** Экспорт Custom требует совместимой Custom Engine Unreal 5.1 с плагином CriWare и его DLL, а также CustomProject с совместимыми голосовыми эталонами. Обычной установки Unreal недостаточно.
- Для Replacer CustomProject необязателен. Если указан, эталоны берутся из него; иначе — из игры. Кэш обновляется при изменении игровых контейнеров.

## Основные функции
- Банки US/JP, официальные локализованные имена, Cue IDs, функции, теги взаимодействий, фильтры и повторяющиеся голоса; сравнение исходного и изменённого звука.
- Импорт аудио, видео и внешних голосовых пакетов; запись с микрофона; обрезка, усиление, устранение клиппинга и максимизация громкости.
- Локальное улучшение голоса, отделение фона и эффекты: реверберация, эхо, высота тона, низкие/высокие частоты, двойной голос, искажение и радио. Прослушивайте до применения; качество зависит от записи.
- Скорость от 0,25x до 3,00x, сохранение тона включено по умолчанию (можно отключить), предпрослушивание и отмена/повтор. Сохранение тона меняет только темп.
- Сохранение и восстановление, недавние проекты, обмен/объединение, миграция банков и копирование по тегам/функциям. Ctrl+Z отменяет; Ctrl+Y или Ctrl+Shift+Z повторяет. Интерфейс и справка на 16 языках.
- Внешние голоса, подтверждённо идентичные игре, считаются оригиналами, а не заменами. Предпрослушивание внешнего звука доступно только при подтверждённых различиях. Для незаменённых голосов выбирайте оригинал или тишину.

## Экспорт Replacer и Custom
**Replacer:** помещает `.pak`, `.utoc` и `.ucas` вместе в папку мода. Исходный банк определяет заменяемого персонажа; переименование проекта или папки не меняет цель. Пустое имя папки использует официальное имя базового персонажа на языке приложения. Мод собственного персонажа должен оставаться установленным: голосовой пакет не содержит персонажа. При импорте держите связанные PAK/UTOC/UCAS вместе. Replacer не запускает Unreal Editor.

**Custom:** помещает `.uasset` в папку мода для Unreal, а `.pak` — в папку мода для игры, с префиксом «Custom»; промежуточные файлы и отчёты — в папку поддержки. Имена папок соответствуют языку приложения. Имя проекта должно точно совпадать с папкой мода/плагина в `Plugins` Unreal. Банк должен соответствовать ID собственного персонажа и US/JP. В настройках укажите CustomProject и Custom Engine.

Экспорты группируются по номеру и имени проекта. Каждая версия начинается с возрастающего номера: при сортировке по имени последняя версия находится в конце. Меню открытия папок предлагает экспорт, изменённое аудио и проекты; без проекта открывает общую папку экспорта. Всегда проверяйте результат в игре.

## Проекты и резервные копии
Перед обновлением закройте приложение и сохраните копию папки. Распакуйте новый ZIP в ту же установку, объединяя папки и заменяя файлы программы. Сохраните Projects, Cache, settings.json, настройки, счётчики и пресеты: их нет в новом ZIP. Не создавайте лишнюю вложенную папку приложения. Не меняйте расположение: старые проекты могут содержать абсолютные пути к аудио. Старые проекты без новых необязательных полей поддерживаются. См. UPDATE.md.

## Проблемы и состав пакета
При отказе в доступе распакуйте в папку с правом записи, например «Документы». Открытие папок повторяется через Проводник; права администратора не запрашиваются, разрешения Windows не меняются. При ошибках Custom проверьте указанный `import.log` и Engine/CriWare. Assets должны соответствовать нужному банку и версии.

Пакет не содержит личных проектов, записей, экспортов, кэша, игровых/эталонных assets или настроек автора. Стандартный ключ и инструменты включены. Лицензии находятся рядом со средой выполнения и библиотеками; сведения о голосовых движках — в `Tools/VoiceAI/NOTICE.txt`. Для поддержки сообщите версии приложения/игры, банк, режим и log. Локальные проверки не заменяют тест в игре.
