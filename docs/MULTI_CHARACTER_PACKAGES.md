# Packages with multiple characters

Use **Open external voice** and select the voice PAK as usual. Keep the mod's companion UTOC/UCAS files in the same directory. If multiple banks are found, the app shows character/folder groups with explicit US/JP bank selection, search and voice counts. Custom labels come from the mod asset folders; they are not official character-name guesses.

Only the selected bank is edited. Each bank can be saved as its own project. To return to the detected package list, use **Project tools > Package characters**. A single-bank package still opens directly.

Custom filenames such as BTLCV_Toas_14_US are accepted when verified against the exact asset path and chunk in the original mod container. ACB/AWB IDs and HCA headers are checked. Legacy metadata are reconciled in app-owned copies; invalid or ambiguous pairs remain blocked. No current game ACB is substituted for missing mod metadata.

For an existing custom-character package, Replacer export preserves the original asset mount and chunk identity. The exported package overrides only the selected voice bank; **keep the original character mod installed**. It does not rebuild the whole character pack. Preview, pairing and package round-trip validation do not replace an in-game test.
